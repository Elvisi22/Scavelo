FAQ

Questions before you start.

How long does a deployment foundation take?
One to two weeks for most products, from €1,200. You get Terraform for matching staging and production, a containerised application, a pipeline that deploys on merge with rollback, centralised logs and a runbook.
Will our team be able to run it without you?
That is the point. Everything is defined as code in your repository, and the runbook covers releases and rollbacks, so anyone on the team can ship safely.
Which CI system do you use?
GitHub Actions by default. If your code lives somewhere else, mention it in your brief and the proposal will say what that changes.
How does fixed pricing actually work?
Send a brief and you get back a one-page scope covering deliverables, price and timeline. Work starts on a 50% deposit and the balance is due on delivery. Anything outside that written scope is quoted separately before it is built, so the final invoice matches the number you agreed.
